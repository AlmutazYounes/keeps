# D010 Edits copy or replace, and a face box is not the file

Context

The viewer can crop, rotate, and straighten a still photo. A person can also mark a face the detector missed.

Decision

Save a copy writes a new file next to the original. Save asks first, then replaces the original file. A face box is stored with the other faces. Adding that box does not change the photo. The new face uses the same 10 photo rule as the Faces page. Videos can be viewed. These edits are for still photos.

Consequences

The original stays put unless Save is confirmed. A missed face can be named, and the same name still merges two groups.
