# D006 Delete goes to Trash

Context

Cleaning the library has to be reversible. A review list can be wrong about a photo.

Decision

Delete asks first. Finder then moves the file to Trash, and the grid drops it. Review scores still photos and lists the strongest matches with a reason. Careful, balanced, and aggressive change which photos appear. A careful pass leaves a named person off the list. Nothing is removed until Delete is chosen.

Consequences

A deleted file can come back from Trash. Review can walk the whole library and still removes nothing by itself. Trash is Finder on this Mac.
