# D013 The gallery is called Keeps

Context

The wordmark said Photos. That is also the library folder and the stills tab, so the app had no name of its own.

Decision

The app is Keeps. The header on every page says Keeps. The stills tab stays Photos. The library folder stays Photos/. The GitHub repo is AlmutazYounes/keeps.

Consequences

A browser tab on the home page says Keeps. Place lookups send the user agent Keeps/1.0. The folder on disk and the Photos tab do not change.
