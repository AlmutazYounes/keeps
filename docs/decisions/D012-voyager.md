# D012 The light map is Voyager

Context

The light tiles were Positron. That style is mostly gray. A place map should show parks and water.

Decision

The light theme uses CARTO Voyager raster tiles. The dark theme stays on dark_all. Both still send the key from gallery/carto.key. This replaces the tile style in D011.

Consequences

Light mode shows green parks and blue water. Dark mode stays dark. The same free key covers both.
